# AI-DLC Workflows のロードマップ

**2026年10月29日にレビューしました。** このレビュー時点の最新の安定版リリースは
[v2.11.2](https://github.com/awslabs/aidlc-workflows/releases/tag/v2.11.2) です。

このロードマップは、提供済みの機能と、プロジェクトの北極星の方向を記録します。いまの実装状況は、Issue とプルリクエストが持っています。リリース内容の全体、互換性の注記、アップグレード手順は、[GitHub Releases](https://github.com/awslabs/aidlc-workflows/releases) にあります。

## 利用できるもの

- **安定版:** 公開済みの安定版リリースに含まれる機能です。
- **プレビュー:** フィードバックのための候補ビルドです。試す前に、選んだプレビューのテスト報告と既知の制限を読んでください。
- **`main` 上:** 統合済みの開発作業です。最新の安定版リリースより先に進んでいることがあります。マージされた PR は、プレビュー公開の対象になります。

[開発とリリースのガイド](../DEVELOPERS.md) が、プレビューのテスト、安定版への昇格、リリースの判断を説明します。

## 北極星のリファレンス

プロジェクトの既存の北極星が扱うのは、設定可能なアンサンブル、ハーネスをまたいだカスタマイズ、適応するワークフロー、証拠に基づく検証、統制されたフィードバックループ、成果物の追跡可能性、共有される組織のナレッジです。

[以前のロードマップのスナップショット](https://github.com/awslabs/aidlc-workflows/blob/764553d96fb80a41d5dfc7b17d4399199f6766da/docs/roadmap.md) は、それ以前の北極星のスコアカードと提供の履歴を残しています。そこに書かれた 2026年9月11日のステータスの記述は歴史的なものです。それ以降の提供には、上のリリースのリンクを使ってください。
