# はじめに・更新情報・ヒントで使い方を知る

> 対象: Andon を初めて使う方、拡張の更新後に変更点を確認したい方  
> 関連: [はじめに（インストール〜初回 Setup）](./getting-started.md) · [Dashboard で現在地と成果物を読む](./reading-workflow.md)

## このガイドでできるようになること

1. 「はじめに」で主要な画面の見方を知る
2. 画面を順に案内するツアーで、自分の案件の現在地・ゲート要求・成果物を確かめる
3. 拡張の更新後に「更新情報」で新機能と変更点を確認する

## はじめに

セットアップ後に初めて Dashboard を開いたとき、一度だけ「はじめに」を表示します。以前の版から使っている方には表示せず、代わりに「更新情報」で新機能をお知らせします。

右上のメニューの「はじめに」、またはコマンドパレットの **`Andon: Show Welcome`** から、いつでも開き直せます。

| 内容                     | 説明                                                                                             |
| ------------------------ | ------------------------------------------------------------------------------------------------ |
| まず押さえる3つのこと    | 現在地、工程の説明とゲート要求、成果物の読み方を実画面で紹介します                               |
| 必要になったら使う機能   | ドキュメント・プラグイン・カスタマイズ・効果測定を、開いたときだけ画像付きで紹介します           |
| 自分のプロジェクトで開く | 状態に応じた次の操作を表示します。案件があればツアー、作業がなければ最初の作業の開始を案内します |

画像はクリックまたは Enter で拡大できます。画像は撮影時点の表示例で、あなたのプロジェクトの状態ではありません。

「あとで読む」を選ぶとステージ一覧に戻り、メニューから開けることを一度だけ案内します。

## 画面を順に案内するツアー

「はじめに」の「画面を順に案内してもらう」で始めます。表示できる案件があるときに利用できます。

ツアーは次の6つの場所を、実際の画面で順に示します。

1. 表示する作業（インテント）の切り替え
2. 現在の工程と状態
3. 工程の一覧
4. 承認で確認すること（ゲート要求）
5. AI が作る成果物
6. メニュー

4と5ではステージ詳細を開きます。「次へ」「戻る」で移動し、「ツアーを終了」または Esc でいつでも終了できます。ツアー中は画面の他の部分を操作できません。終了すると、ツアーを始めた画面に戻ります。「はじめに」から始めた場合はステージ一覧に移ります。

表示する場所が見つからない場合は、説明だけを表示して先へ進めます。ツアーは画面を開くだけで、AI-DLC の状態は変更しません。

## 更新情報

拡張の更新後に初めて Dashboard を開いたとき、新しい変更があれば右側に「更新情報」を表示します。インテントの選択画面が開く場合は重ねて表示せず、次に Dashboard を開いたときに表示します。

一覧を開いた時点で既読になります。「新着」の印は一覧を閉じるまで残ります。各項目のボタンから、変わった画面を直接開けます。

右上のメニューの「更新情報」には未読の件数を表示します。コマンドパレットの **`Andon: Show What's New`** からも開けます。

拡張を更新してウィンドウを再読み込みすると、新機能がある場合に通知を表示します。「更新情報を見る」で一覧を開けます。「更新を確認」で新しい版が見つかったときは、確認画面にその版の主な変更を表示します。この変更一覧は GitHub のリリースノートから作ります。

ここで扱うのは Andon 拡張の変更です。aidlc-workflows 本体の変更は「ドキュメント」の更新履歴を参照してください。

## 画面ごとのヒント

ステージ詳細・ドキュメント・カスタマイズ・効果測定を初めて開いたとき、画面の上部に短いヒントを表示します。新しい機能は、その機能がある画面にも「新機能」として一度表示します。

× で閉じると、次からは表示しません。「はじめに」の「画面ごとのヒントをもう一度表示する」で元に戻せます。ツアー中はヒントを表示しません。

## 記録する場所

表示済みの状態は、VS Code / Cursor が拡張機能に用意する保存領域に利用者ごとに保存します。ワークスペースや `aidlc/` には書き込みません。

以前の版から更新したかどうかは、拡張が以前に保存した値の有無で判断します。利用者ごとの値と、開いているワークスペースの値のどちらかがあれば、以前から使っていると判断します。拡張の「更新を確認」などで作られる保存フォルダも手がかりにします。

以前の版を別のフォルダでだけ使い、ドキュメントの表示言語や質問を使わず、拡張を手動で入れ替えた場合は、初めての利用として扱います。このときは「はじめに」が開き、それまでの更新情報は既読になります。更新情報はメニューからいつでも開けます。
