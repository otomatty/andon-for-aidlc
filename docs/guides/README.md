# Andon for AI-DLC — 使い方ガイド

ユースケースごとの手順書です。初めてなら [はじめに](./getting-started.md) から進めてください。

AI-DLCの運用で迷ったら、[aidlc-workflows Tips一覧](./aidlc-workflows-tips.md)からテーマごとの記事を選んでください。ドキュメントのトップページの「運用Tips」の「運用Tipsをすべて見る」、または「ドキュメント一覧」の「ワークフロー」の「運用Tips」から開けます。各記事に対象バージョン・確認日・根拠と関連記事を掲載しています。

Dashboard の「ドキュメント」を開くと、トップページで「ページを探す」にページ名の一部を入れて探せます。初めてなら「はじめて読むなら」を上から順に、目的がはっきりしていれば「目的から選ぶ」の各カードからページを直接開けます。下の使い方ガイドはトップページの「拡張機能の使い方」、または「ドキュメント一覧」の「拡張機能」タブから読めます。一覧では「ワークフロー」と「拡張機能」を切り替えられます。「ワークフロー」には公式ドキュメント・更新履歴・運用Tipsをまとめています。「ドキュメント一覧」の「トップページへ」からドキュメントのトップページへ戻れます。
